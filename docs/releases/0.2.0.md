# Quietly 0.2.0 — early sideloading beta

Own uploads and followed-profile Reels can now open individually without adding
every account to the saved Friends list. Own profiles are recognized by Instagram's
Edit profile control. Followed profiles are recognized by supported Following
controls while using People I follow. Saved friends work as an explicit fallback.

Fixed repeated WebKit suspension calls that could leave a selected video unable
to play after loading, opening a sheet or returning to the app.

The global Reels and Explore feeds stay blocked. Profile and DM viewers that mount
an in-page video list are restricted to one selected video; closing returns to the
source page. This is an early testing release: Instagram layouts and languages can
change, so fixture tests are not a guarantee for every private account or video.

Free and open source under the MIT license. Requires iOS/iPadOS 17+ and SideStore
or AltStore Classic. A free Apple Account requires signing refreshes every seven
days. This is not an App Store or AltStore PAL build. Message alerts only work while
the app is open; background DM push is not implemented.

Read [installation instructions](https://github.com/botondberdedev-cell/quietly/blob/main/docs/sideloading.md).
